<analysis>**original_problem_statement:**
Crie um aplicativo SaaS global chamado CLOCKLN, uma plataforma inteligente de controle de ponto corporativo. O sistema deve suportar diferentes tipos de usuários (Funcionário, RH, Gerente) com permissões específicas. As funcionalidades principais incluem registro de ponto automático (via totem com QR code/NFC e geolocalização para remotos), cálculo de horas, gestão de banco de horas, organização de documentos trabalhistas (atestados), geração de relatórios, e um sistema de notificações. O sistema deve ser multilíngue (com 17 idiomas de lançamento, incluindo suporte RTL), seguro (multi-tenant, LGPD/DSGVO), e ter um design moderno e minimalista. O modelo de negócio é SaaS por assinatura com diferentes planos (Free, Pro, Business).

**PRODUCT REQUIREMENTS have evolved to include:**
- Check-in via QR code scan no totem.
- Tema escuro para a interface.
- Funcionários podem visualizar dias de férias e faltas.
- Modo quiosque para os totens em tablets.
- Upload de documentos para funcionários.
- Clock-in remoto restrito por geolocalização para funcionários designados como remoto ou híbrido.
- Um mapa visual para o RH visualizar a localização dos clock-ins remotos.

**User's preferred language**:
Português (Brasil). The next agent MUST respond in Portuguese (Brasil) only.
