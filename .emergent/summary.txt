<analysis>**original_problem_statement:**
Crie um aplicativo SaaS global chamado CLOCKLN, uma plataforma inteligente de controle de ponto corporativo. O sistema deve suportar diferentes tipos de usuários (Funcionário, RH, Gerente) com permissões específicas. As funcionalidades principais incluem registro de ponto automático (via totem com QR code/NFC e geolocalização para remotos), cálculo de horas, gestão de banco de horas, organização de documentos trabalhistas (atestados), geração de relatórios, e um sistema de notificações. O sistema deve ser multilíngue, seguro (multi-tenant, LGPD/DSGVO), e ter um design moderno e minimalista. O modelo de negócio é SaaS por assinatura com diferentes planos (Free, Pro, Business).

**PRODUCT REQUIREMENTS have evolved to include:**
-   Check-in via QR code scan no totem.
-   Tema escuro para a interface.
-   Funcionários podem visualizar dias de férias e faltas.
-   Modo quiosque para os totens em tablets.
-   Upload de documentos para funcionários.
-   Clock-in remoto restrito por geolocalização para funcionários remoto ou híbrido.
-   Um mapa visual para o RH visualizar a localização dos clock-ins remotos.
-   Sistema de notificações para o RH e alertas automáticos (ponto fora do raio).
-   Papel de Gerente com visualização de equipe restrita e aprovações.
-   Planos de assinatura (SaaS) com integração Stripe.
-   Geração de relatórios em PDF/Excel.
-   Lógica avançada de banco de horas e aprovação de horas extras.
-   Funcionalidade de PWA (Progressive Web App) para uso mobile.
-   Notificações por email (via SendGrid).
-   Um painel de Super Admin para conceder acesso ilimitado (VIP) a empresas específicas.
-   **[NEW]** Correção de bugs de tradução e layout mobile.
